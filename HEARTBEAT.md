## Research Automation (LM Studio Mode)

**Schedule (5 runs per day):**
- **06:00** — OpenClaw updates (morning briefing)
- **12:00** — AI models check (midday)
- **18:00** — AI models check (evening)
- **20:00** — Philosophy/personal growth
- **22:00** — AI income opportunities

**Note:** Research now uses LM Studio directly via Python scripts. No Ollama needed!

---

### How It Works
1. **LM Studio** runs continuously with Qwen 3.5 loaded
2. **Cron job** triggers at scheduled time
3. **Python script** calls LM Studio API directly
4. **Results** saved to `memory/research/YYYY-MM-DD_[topic].md`
5. **No subagents** - direct API calls are faster and more reliable

## Migration Notes (2026-04-01)

**Old System:**
- Ollama with Qwen 2.5/3.5
- Subagents with 60-180s timeouts
- Pre-warm cron jobs every 3 hours
- Complex auth workarounds

**New System:**
- LM Studio with Qwen 3.5
- Direct API calls via Python scripts
- No pre-warm needed (always loaded)
- 55ms response time
- Thinking mode disabled

**Benefits:**
- 100x faster (55ms vs 60s)
- Simpler architecture
- No Ollama needed
- More reliable
