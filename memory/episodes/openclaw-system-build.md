## Decisions That Mattered

1. **Local-first approach** — Privacy, no API costs for routine tasks
2. **Partnership over command** — Mutual respect, collaborative decisions
3. **Document everything** — MEMORY.md, daily logs, research outputs
4. **Automate aggressively** — If it repeats, cron it
5. **Fail gracefully** — Downgrade when needed, keep backups

---

## Lessons for Future Projects

- **Start simple, expand gradually** — Don't try to build everything at once
- **Memory is foundation** — Without continuity, an AI is just a chatbot
- **Test early, test often** — The Ollama ghost taught us this
- **Community solutions** — When native features fail, look to the community
- **Health over perfection** — 77/100 is good; chasing 100/100 is diminishing returns
