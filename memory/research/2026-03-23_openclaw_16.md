# OpenClaw Updates Research - 2026-03-23

## Latest Version Releases

### v2026.3.22 (March 23, 2026) - LATEST
**Major breaking release with significant changes:**
- **ClawHub Integration**: Plugin installs now prefer ClawHub over npm for npm-safe names
- **Browser/Chrome MCP**: Removed legacy Chrome extension relay path - use `openclaw doctor --fix` to migrate
- **New Matrix Plugin**: Official matrix-js-sdk backed plugin (migration guide available)
- **Image Generation**: Standardized on core `image_generate` tool, removed nano-banana-pro skill
- **Plugin SDK**: New public SDK surface at `openclaw/plugin-sdk/*`, old extension-api removed
- **Security Hardening**: Blocked build-tool JVM injection, glibc tunable exploitation, .NET dependency hijacking

### v2026.3.13-1 (March 14, 2026)
Recovery release for broken v2026.3.13 tag. Key fixes:
- Fixed compaction token count sanity check
- Telegram thread media transport policy fixes
- Discord gateway metadata fetch failure handling
- Session reset preservation of lastAccountId/lastThreadId
- Android chat settings UI redesign
- iOS onboarding welcome pager

### v2026.2.23 (February 24, 2026)
Security-focused release:
- HTTP security headers (Strict-Transport-Security) for HTTPS deployments
- Browser SSRF policy defaults to "trusted-network" mode
- Sensitive dynamic keys redacted in config snapshots
- Obfuscated commands trigger explicit approval
- Claude Opus 4.6 support via Kilo Gateway
- Moonshot video support and improved citation extraction

## Breaking Changes Summary

Users should run `openclaw doctor --fix` to migrate:
- Browser config (extension relay → existing-session/user)
- Legacy env names (CLAWDBOT_* → OPENCLAW_*)
- State directory (.moltbot → .openclaw)
- Matrix plugin (if using previous public version)
