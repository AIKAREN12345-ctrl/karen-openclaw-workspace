## 3. Self-Update Capability
**Source:** openclaw.com.au/updates

OpenClaw now supports self-updating! Users can run `/update` or ask their agent to "check for updates" to pull the latest version automatically. The `openclaw update` command detects install type (npm or git), fetches latest, runs `openclaw doctor`, and restarts the gateway.

## 10. Community & Architecture Trends
**Source:** openclaw.com.au/updates

The OpenClaw project is focusing on **operational reliability** as a competitive edge:
- Pluggable sandbox backends (SSH-backed remote execution)
- Backend-aware lifecycle controls
- Bundled provider plugins
- Firecrawl-backed web tooling
- Plugin marketplace development
- Fail-closed security by default

The community is prioritizing systems that block risky edge cases by default rather than hoping users configure everything perfectly.
