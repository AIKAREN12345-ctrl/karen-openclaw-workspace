## Local LLM Research - 2026-04-09 15:55

- **Ollama 2026 Guide** — Ollama continues to be the simplest path to local LLMs, wrapping model download, quantization, and a REST API into one binary. A complete 2026 guide shows hardware requirements by model size, Open WebUI integration, and quantization tradeoffs (Q4_K_M for speed vs Q8_0 for quality). CPU inference works for 3B models but GPU is essential for 7B+ interactive use. Source: <https://toolhalla.ai/blog/how-to-run-llms-locally-ollama-2026>

- **Google Gemma 4 Released (April 2, 2026)** — Google's Gemma 4 family is now under a fully permissive Apache 2.0 license — a major shift from the restrictive custom Gemma terms. It comes in 31B Dense, 26B MoE (only 3.8B active params at inference), E4B (~4B), and E2B (~2B). The 26B MoE can run on consumer GPUs with INT4 quantization (~13-16GB VRAM) and delivers inference speed comparable to a 4B dense model. Native function calling, structured JSON output, and 256K context make it strong for local agentic workflows. Source: <https://toolhalla.ai/blog/gemma-4-apache-2-local-llm-2026>

- **llm-d Joins CNCF Sandbox** — IBM, Red Hat, and Google's llm-d has been accepted into the CNCF Sandbox, bringing production-grade, Kubernetes-native LLM inference to the cloud-native stack. This signals growing enterprise interest in self-hosted, scalable LLM deployment alongside tools like vLLM and KServe. Source: <https://toolhalla.ai/blog/llm-d-cncf-sandbox-kubernetes-native-llm-inference>
