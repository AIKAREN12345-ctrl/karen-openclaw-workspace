## Latest Release Summary

### v2026.3.12 (Released March 13, 2026)
**Latest stable release** with significant new features and security fixes.

#### Major Changes:
- **New Control UI/Dashboard-v2**: Complete refresh with modular overview, chat, config, agent, and session views, plus command palette, mobile bottom tabs, and enhanced chat tools (slash commands, search, export, pinned messages)
- **Fast Mode for OpenAI/GPT-5.4**: Configurable session-level fast toggles across /fast, TUI, Control UI, and ACP
- **Fast Mode for Anthropic/Claude**: Maps shared /fast toggle to direct Anthropic API service_tier requests
- **Provider Plugin Architecture**: Ollama, vLLM, and SGLang moved to provider-plugin architecture for more modular onboarding
- **Kubernetes Support**: New starter K8s install path with raw manifests, Kind setup, and deployment docs
- **Subagent sessions_yield**: Orchestrators can end current turn immediately and carry hidden follow-up payload into next session turn
- **Slack Block Kit Support**: Agents can send Block Kit messages through standard Slack outbound delivery

#### Security Fixes (2 critical):
- **Gateway/WebSocket**: Enforced browser origin validation for all browser-originated connections to prevent cross-site WebSocket hijacking (GHSA-5wcw-8jjv-m286)
- **Device Pairing**: Switched /pair and QR setup codes to short-lived bootstrap tokens (no more embedded shared gateway credentials)
- **Plugin Auto-load**: Disabled implicit workspace plugin auto-load to prevent cloned repositories from executing workspace plugin code without explicit trust

### v2026.3.11 (Released March 12, 2026)

#### New Features:
- **OpenRouter Hunter Alpha & Healer Alpha**: Temporary free stealth models available for ~1 week
- **iOS Home Canvas**: Bundled welcome screen with live agent overview, docked toolbar, adapts to smaller phones
- **macOS Chat UI**: Chat model picker, persist thinking-level selections across relaunch
- **Ollama Onboarding**: First-class Ollama setup with Local or Cloud + Local modes, browser-based cloud sign-in
- **OpenCode Go Provider**: New provider, treats Zen and Go as one OpenCode setup
- **Multimodal Memory**: Opt-in image and audio indexing for memorySearch.extraPaths with Gemini gemini-embedding-2-preview
- **Discord Auto Threads**: Configurable autoArchiveDuration (1h, 1d, 3d, 1w)
- **ACP Resume Session**: Optional resumeSessionId for runtime: "acp" to resume existing ACPX/Codex conversations

#### Breaking Changes:
- **Cron/Doctor**: Tightened isolated cron delivery - cron jobs can no longer notify through ad hoc agent sends or fallback main-session summaries. Use `openclaw doctor --fix` for migration

### v2026.3.8 (Released March 8, 2026)

#### New Features:
- **CLI Backup**: `openclaw backup create` and `openclaw backup verify` for local state archives
- **Talk Mode**: Configurable `talk.silenceTimeoutMs` for auto-sending transcripts
- **TUI Workspace Agent**: Infers active agent from current workspace when launched inside configured agent workspace
- **Brave Web Search LLM Context**: Opt-in `tools.web.search.brave.mode: "llm-context"` for extracted grounding snippets
- **ACP Provenance**: Optional ACP ingress provenance metadata and visible receipt injection

#### Fixes:
- macOS launchd restart recovery fixes
- Android Play distribution changes (removed self-update, background location, screen.record)
- Telegram DM deduplication per agent
- Cron announce delivery fixes for Telegram
- Browser relay improvements for WSL2

### v2026.2.12 (Released February 12, 2026)
**Major security release** - 40 security fixes

#### Security Highlights:
- **SSRF Hardening**: Explicit deny policies, hostname allowlists, per-request URL input caps, audit logging
- **Prompt Injection Defenses**: Browser snapshots and web tool outputs wrapped as untrusted content by default
- **Webhook Auth Hardening**: Constant-time secret comparison, per-client auth-failure throttling
- **Sandbox Confinement**: Skill sync destinations confined to sandbox skills/ root
- **Session Path Traversal**: Hardened transcript path resolution

#### New Models:
- GLM-5 (Z.AI) with expanded endpoint support
- MiniMax M2.5 and M2.5-Lightning (replacing M2.1)

#### Cron Scheduler Overhaul:
- Fixed jobs skipping when nextRunAtMs advances
- Fixed duplicate fires when multiple jobs trigger simultaneously
- Isolated bad jobs from breaking others
- Fixed one-shot at jobs re-firing after restart
- Fixed timer re-arming failures during execution
