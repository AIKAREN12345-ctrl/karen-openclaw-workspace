# OpenClaw 2026 Updates Research

**Research Date:** 2026-04-16

## Overview

OpenClaw has released multiple significant updates in 2026, with the latest stable versions being **2026.4.14** and **2026.4.15** (released April 14-15, 2026). These releases focus on security hardening, new features for memory and dreaming, local model improvements, and enhanced integrations.

---

## 1. New Features

### Memory & Dreaming System
- **Active Memory Plugin** (2026.4.10+): New optional plugin that gives OpenClaw a dedicated memory sub-agent before the main reply. Automatically pulls relevant preferences, context, and past details without manual "remember this" commands.
- **Memory-Wiki** (2026.4.7+): Structured knowledge vault with claim/evidence fields, contradiction tracking, freshness signals, compiled digests, and Obsidian-friendly output.
- **Dreaming Improvements**: ChatGPT import ingestion, "Imported Insights" and "Memory Palace" diary subtabs, grounded REM backfill lane for historical notes.
- **Grounded REM Backfill**: Historical `rem-harness --path` support to replay old daily notes into Dreams and durable memory.

### CLI & Inference
- **`openclaw infer`**: New headless CLI surface for model runs, image work, audio, TTS, video, web search, and embeddings.
- **`openclaw exec-policy`**: Local command with `show`, `preset`, and `set` subcommands for synchronizing exec tool config with local approvals file.
- **Model Auth Status Card**: Control UI now shows OAuth token health and provider rate-limit pressure with attention callouts for expiring tokens.

### Integrations
- **GitHub Copilot**: New embedding provider for memory search with dedicated Copilot embedding host helper.
- **LM Studio Provider**: Bundled provider with onboarding, runtime model discovery, stream preload support, and memory-search embeddings for local models.
- **Microsoft Teams**: Added reaction support, reaction listing, Graph pagination, and delegated OAuth setup.
- **Feishu**: Improved document comment sessions with richer context parsing, comment reactions, and typing feedback.
- **Telegram Forum Topics**: Surface human topic names in agent context and persist learned names to session sidecar store.

### Media & Generation
- **Video Generation Upgrades**: URL-only generated asset delivery, typed `providerOptions`, reference audio inputs, per-asset role hints, `adaptive` aspect-ratio support.
- **macOS Talk Mode**: Experimental local MLX speech provider with explicit provider selection, local utterance playback, interruption handling.

## 2. Security Updates

### Critical Security Fixes
- **Exec Approval Secrets Redaction**: Secrets now redacted in exec approval prompts so inline approval review can no longer leak credential material.
- **Gateway Auth Rotation**: Active gateway bearer now resolved per-request via `getResolvedAuth()`, so rotated secrets stop authenticating immediately instead of remaining valid until restart.
- **MCP Loopback Auth**: Switched `/mcp` bearer comparison to constant-time `safeEqualSecret` and reject non-loopback browser-origin requests.
- **Memory/QMD Path Restrictions**: `memory_get` now rejects reads of arbitrary workspace markdown paths - only allows canonical memory files (`MEMORY.md`, `memory.md`, `DREAMS.md`, `dreams.md`, `memory/**`).
- **Agent File Access**: Workspace file access now routes through shared `fs-safe` helpers with symlink rejection and real-path resolution from file descriptors.

### Browser & SSRF Hardening
- Enforced SSRF policy on snapshot, screenshot, and tab routes
- Re-run blocked-destination safety checks after interaction-driven navigations
- Restore hostname navigation under default SSRF policy while keeping strict mode reachable
- Managed loopback CDP control bypasses SSRF policy for local control plane

### Additional Security Measures
- **Heartbeat Security**: Force owner downgrade for untrusted `hook:wake` system events
- **Microsoft Teams SSO**: Enforce sender allowlist checks on SSO signin invokes
- **Config Redaction**: Redact `sourceConfig` and `runtimeConfig` alias fields in `redactConfigSnapshot`
- **Feishu Webhook**: Harden webhook transport - refuse to start without `encryptKey`, reject unsigned requests
- **Slack Interactions**: Apply global `allowFrom` owner allowlist to channel block-action and modal interactive events

## 3. Performance Improvements

### Local Model Optimizations
- **Local Model Lean Mode**: Experimental `agents.defaults.experimental.localModelLean: true` drops heavyweight default tools (`browser`, `cron`, `message`) for weaker local-model setups.
- **Ollama Context Window Caching**: Cache `/api/show` context-window and capability metadata during model discovery to reduce repeated fetches.
- **Compaction Improvements**: Cap compaction reserve-token floor to model context window so small-context local models (e.g., Ollama with 16K tokens) no longer trigger context-overflow errors.
- **Ollama Usage Reporting**: Send `stream_options.include_usage` for Ollama streaming completions so local runs report real usage instead of bogus prompt-token counts.

### Core Performance
- **Plugin Loading**: Narrow CLI, provider, and channel activation to manifest-declared needs, avoiding loading unrelated plugin runtime.
- **Doctor/Plugins**: Cache external `preferOver` catalog lookups within each plugin auto-enable pass to reduce CPU usage.
- **Context Engine**: Run opt-in turn maintenance as idle-aware background work so foreground turns don't wait on proactive maintenance.
- **Gateway Keepalive**: Stop marking WebSocket tick broadcasts as droppable so slow clients don't self-disconnect during long-running work.

### Memory & Dreaming Performance
- **Active Memory Recall**: Improved lexical fallback ranking and hybrid search to find memories more consistently.
- **Dreaming Event Management**: Consume managed heartbeat events exactly once, preventing replay on later heartbeats after scheduled runs were consumed.
- **Memory-LanceDB Cloud Storage**: Add cloud storage support so durable memory indexes can run on remote object storage instead of local disk only.
