## 📊 Latest Stable Release: v2026.3.23

Released March 23, 2025 - This is a significant patch release with numerous fixes and improvements.

### Key Changes in v2026.3.23

#### Model & Provider Updates
- **ModelStudio/Qwen**: Added standard (pay-as-you-go) DashScope endpoints for China and global Qwen API keys alongside existing Coding Plan endpoints
- **Mistral models**: Lowered bundled Mistral max-token defaults to safe output budgets
- **OpenAI**: Default setup model switched to `openai/gpt-5.4`, Codex kept on `openai-codex/gpt-5.4`

#### UI Improvements
- Consolidated button primitives (btn--icon, btn--ghost, btn--xs)
- Refined Knot theme to black-and-red palette with WCAG 2.1 AA contrast
- Added config icons for Diagnostics/CLI/Secrets/ACP/MCP sections
- Replaced roundness slider with discrete stops
- Improved accessibility with aria-labels across usage filters

#### Security Enhancements
- CSP/Control UI: Compute SHA-256 hashes for inline blocks in served index.html
- Diagnostics/cache trace: Strip credential fields from cache-trace JSONL output
- Config/warnings: Suppress confusing "newer OpenClaw" warning for same-base correction releases

#### Bug Fixes
- **Browser/Chrome MCP**: Wait for existing-session browser tabs to become usable after attach
- **Browser/CDP**: Reuse already-running loopback browsers after brief reachability miss
- **Agents/web_search**: Use active runtime web_search provider instead of stale/default selection
- **ClawHub/macOS**: Honor macOS auth config and XDG auth paths for saved ClawHub credentials
- **Auth/OpenAI tokens**: Stop live gateway auth-profile writes from reverting freshly saved credentials
- **Plugins/ClawHub**: Resolve plugin API compatibility against active runtime version at install time

## 🚀 Major Release: v2026.3.22 (March 22, 2026)

### Breaking Changes
- **Plugins/install**: Bare `openclaw plugins install` now prefers ClawHub before npm for npm-safe names
- **Browser/Chrome MCP**: Removed legacy Chrome extension relay path, bundled extension assets, and `driver: "extension"`
- **Tools/image generation**: Standardized on core `image_generate` tool, removed nano-banana-pro skill wrapper
- **Plugins/SDK**: New public plugin SDK surface is `openclaw/plugin-sdk/*`; `openclaw/extension-api` removed
- **Plugins/Matrix**: New Matrix plugin backed by official matrix-js-sdk (migration required)
- **Config/env**: Removed legacy `CLAWDBOT_*` and `MOLTBOT_*` compatibility env names
- **Config/state**: Removed legacy `.moltbot` state-dir and `moltbot.json` auto-detection

### New Features
- **ClawHub/install**: Native `openclaw skills search|install|update` flows
- **Plugins/marketplaces**: Claude marketplace registry resolution and plugin@marketplace installs
- **Commands/plugins**: Owner-gated `/plugins` and `/plugin` chat commands
- **Install/update**: Allow package-manager installs from GitHub main via `openclaw update --tag main`
- **Sandbox/runtime**: Pluggable sandbox backends with OpenShell backend
- **Sandbox/SSH**: Core SSH sandbox backend with secret-backed key support
- **Browser/existing-session**: Support `browser.profiles.*.userDataDir` for Brave, Edge, and other Chromium browsers
- **Web tools**: Added Exa, Tavily, and Firecrawl as bundled web-search plugins
- **Models/Anthropic Vertex**: Core support for Claude via Google Vertex AI
- **Models/OpenAI**: Native forward-compat support for gpt-5.4-mini and gpt-5.4-nano
- **Commands/btw**: Add `/btw` side questions for quick tool-less answers

## 🔒 Security Focus: v2026.2.13 (February 13, 2026)

Described as "the most security-focused release to date" with over 20 security-specific commits.

### Security Hardening
- Mandatory TLS 1.3
- Stricter gateway authentication
- Native warnings for unauthenticated exposure
- Addressed SSRF vulnerabilities
- Credential exposure fixes
- Voice-call/webhooks: Reject missing provider signature headers
- Exec/env sandbox: Block build-tool JVM injection and glibc tunable exploitation
