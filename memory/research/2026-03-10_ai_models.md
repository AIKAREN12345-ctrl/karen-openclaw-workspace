## Key Findings

### 1. Anthropic Claude Sonnet 4.6 Released (Feb 17, 2026)
- **Major upgrade** across coding, computer use, long-context reasoning, agent planning, knowledge work, and design
- **1M token context window** in beta - enough for entire codebases, lengthy contracts, or dozens of research papers
- **Pricing:** $3/$15 per million tokens (same as Sonnet 4.5)
- **Performance:** Approaches Opus-level intelligence; users preferred it over Sonnet 4.5 ~70% of the time and over Opus 4.5 ~59% of the time
- **Computer use improvements:** Major gains on OSWorld benchmark; human-level capability in navigating complex spreadsheets and multi-step web forms
- **Safety:** Extensive evaluations show it to be as safe as or safer than other recent Claude models

### 2. OpenAI Acquires Promptfoo (March 9, 2026)
- OpenAI acquiring **Promptfoo**, an AI security platform used by 25% of Fortune 500 companies
- Will integrate into **OpenAI Frontier** (enterprise platform for AI coworkers)
- Provides automated security testing, red-teaming, and vulnerability remediation
- Promptfoo has an open-source CLI/library that will continue to be maintained

### 3. OpenAI Codex Security - Research Preview (March 6, 2026)
- New **application security agent** that identifies complex vulnerabilities
- Scanned 1.2M+ commits in beta, identifying 792 critical and 10,561 high-severity findings
- **84% noise reduction** and 90%+ reduction in over-reported severity since initial rollout
- Discovered and reported vulnerabilities in OpenSSH, GnuTLS, GOGS, Thorium, PHP, and Chromium (14 CVEs assigned)
- Available to ChatGPT Pro, Enterprise, Business, and Edu customers

### 4. OpenAI Walking Away from Oracle Stargate Expansion (March 9, 2026)
- OpenAI ending plans to expand Stargate data center with Oracle in Abilene, Texas
- Reason: Want clusters with **newer Nvidia GPUs** (Vera Rubin) rather than Blackwell
- Highlights challenge: Data centers take 12-24 months to build, but Nvidia now releases new chips annually
- Oracle stock down 23% YTD, lost over half its value since September peak

### 5. Anthropic vs. Pentagon Conflict Escalates (March 4-9, 2026)
- Department of War designated Anthropic as a **"supply chain risk"**
- Root cause: Anthropic's two exceptions - no fully autonomous weapons and no mass domestic surveillance
- Anthropic CEO Dario Amodei stated the company will **challenge the designation in court**
- Defense contractors already backing off from Claude "out of an abundance of caution"
- Ironically, Anthropic usage is **booming** - breaking daily signup records globally

### 6. OpenAI Delays ChatGPT "Adult Mode" (March 7, 2026)
- Feature originally planned for Q1 2026 has been delayed
- OpenAI focusing on "higher priority" work: intelligence gains, personality improvements, personalization

### 7. Microsoft Integrating Claude Cowork into Copilot (March 9, 2026)
- Microsoft bringing **Claude Cowork** to Copilot through Frontier program
- Built in collaboration with Anthropic for "long-running, multi-step tasks"
- Available in preview later this month

### 8. Anthropic Claude Code - Code Review Feature (March 9, 2026)
- New multi-agent **Code Review** tool in research preview
- Runs agents in parallel to catch "bugs human reviewers often miss"
- Available for Enterprise and Teams customers

### 9. Qualcomm Arduino Ventuno Q Announced (March 9, 2026)
- New single-board computer for **robots and AI**
- Powered by Dragonwing IQ8 processor, 16GB RAM, **40 TOPS NPU**
- Designed for autonomous machines responding to sensor input
