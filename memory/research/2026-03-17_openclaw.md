## Latest Release: v2026.3.13-1 (Recovery Release)

**Published:** March 14, 2026 (18:04 UTC)

This is a recovery release that uses v2026.3.13-1 because GitHub immutable releases do not allow reusing v2026.3.13 after publication. The npm version remains 2026.3.13.

### Key Fixes in v2026.3.13:

**Core System:**
- **Compaction fix:** Uses full-session token count for post-compaction sanity check
- **Session reset:** Preserves lastAccountId and lastThreadId on session reset
- **Memory bootstrap:** Fixed duplicate loading of memory files on case-insensitive mounts
- **Persona continuity:** Preserves persona and language continuity in compaction summaries

**Browser & Automation:**
- **Browser batch actions:** Normalized batch act dispatch for selector and batch support
- **Browser driver validation:** Hardened existing-session driver validation and session lifecycle
- **Chrome DevTools attach mode:** Official support for signed-in browser sessions
- **Built-in profiles:** Added profile="user" and profile="chrome-relay" support

**Platform & Security:**
- **Docker:** Added OPENCLAW_TZ timezone support and apt-get upgrade to all Dockerfiles
- **Security:** Prevented gateway token leak in Docker build context
- **Discord:** Fixed gateway metadata fetch failures
- **Telegram:** Threaded media transport policy into SSRF protection; retry inbound media downloads over IPv4 fallback

**Cron & Agents:**
- **Cron:** Prevent isolated cron nested lane deadlocks
- **Cron:** Can now target current or named session
- **Agents:** Drop Anthropic thinking blocks on replay
- **Agents:** Respect explicit user compat overrides for non-native openai-completions
- **Ollama:** Hide native reasoning-only output

**Mobile (iOS/Android):**
- **iOS:** Added onboarding welcome pager before gateway setup
- **Android:** Redesigned chat settings UI with grouped device and media sections
- **Android:** Use Google Code Scanner for onboarding QR
- **macOS:** Respect exec-approvals.json settings in gateway prompter
- **macOS:** Prevent PortGuard from killing Docker Desktop in remote mode

**UI/UX:**
- **Dashboard:** Fixed chat history reload storm
- **Chat:** Keep oversized chat replies readable
- **Chat:** Stop dashboard chat history reload storm
- **CLI:** Aligned xhigh thinking help text

## Community News & Trends

### Project Direction:
- OpenClaw is optimizing for **human-in-the-loop reliability**
- Focus on **trust and stability** over flashy features
- **Security work** remains front-and-center (auth, SSRF policy, webhook hardening, scoped approvals)

### Notable Patterns:
- Wide spread of first-time contributors in recent releases (healthy project signal)
- Fixes cluster around routing correctness, auth handling, and delivery reliability
- Strong emphasis on **composable operator systems** rather than "one giant prompt"

### Broader AI Agent Trend (2026):
The winning agent stacks are converging on:
- **Grounded autonomy** with explicit control boundaries
- **Better browser attachment** (working with signed-in sessions)
- **Stronger sandbox choices** and **health monitoring**
- **Stateful operator systems** with session resume and memory continuity
