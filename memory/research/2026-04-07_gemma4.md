## Overview

Gemma 4 is Google's newest family of open-weight AI models, announced on **April 2, 2026**. Built from the same research and technology as Gemini 3, Gemma 4 represents a significant leap in "intelligence-per-parameter" — delivering frontier-level capabilities at smaller sizes than competitors.

**Key Highlights:**
- Apache 2.0 license (commercially permissive)
- 400M+ Gemma downloads since first generation
- 100,000+ model variants in the "Gemmaverse"
- Ranks #3 (31B) and #6 (26B) on Arena AI text leaderboard
- Outcompetes models 20x its size

---

## Model Sizes & Variants

Gemma 4 comes in **4 distinct sizes** tailored for different hardware and use cases:

### Edge Models (Mobile/IoT)
| Model | Effective Params | Total Params | Context | Modalities | Memory (BF16) |
|-------|-----------------|--------------|---------|------------|---------------|
| **E2B** | 2.3B | 5.1B | 128K | Text, Image, Audio | 9.6 GB |
| **E4B** | 4.5B | 8B | 128K | Text, Image, Audio | 15 GB |

### Workstation Models (Local/Cloud)
| Model | Params | Active Params | Context | Modalities | Memory (BF16) |
|-------|--------|---------------|---------|------------|---------------|
| **26B MoE** | 25.2B | 3.8B | 256K | Text, Image | 48 GB |
| **31B Dense** | 30.7B | 30.7B | 256K | Text, Image | 58.3 GB |

**Notes:**
- "E" = Effective parameters (uses Per-Layer Embeddings for efficiency)
- MoE = Mixture of Experts (only activates 3.8B params per token)
- E2B/E4B include native audio input; larger models do not

## Key Capabilities

### 1. Advanced Reasoning
- Multi-step planning and deep logic
- Configurable "thinking modes" via `<|think|>` token
- Massive improvements in math benchmarks

### 2. Agentic Workflows
- **Native function calling** support
- Structured JSON output
- Native system instructions (`system` role)
- Build autonomous agents that interact with tools/APIs

### 3. Code Generation
- High-quality offline code generation
- LiveCodeBench v6: 80% (31B), 77.1% (26B)
- Codeforces ELO: 2150 (31B) — competitive programming level
- Turns workstations into local-first AI coding assistants

### 4. Multimodal Understanding
- **All models:** Text + Image (variable resolution/aspect ratio)
- **E2B/E4B only:** Native audio input (speech recognition)
- Vision tasks: OCR, chart understanding, document parsing
- Variable image token budgets: 70, 140, 280, 560, 1120 tokens

### 5. Long Context Windows
- Edge models: **128K tokens**
- Workstation models: **256K tokens**
- Can process entire code repositories or long documents

### 6. Multilingual
- Natively trained on **140+ languages**

## Ollama Integration

Gemma 4 is available on Ollama with **1.2M+ downloads** (as of April 7, 2026):

```bash
# Default model (E4B variant, 9.6GB)
ollama run gemma4

# Specific variants
ollama run gemma4:e2b      # 7.2GB - Edge 2B
ollama run gemma4:e4b      # 9.6GB - Edge 4B
ollama run gemma4:26b      # 18GB - MoE workstation
ollama run gemma4:31b      # 20GB - Dense workstation
ollama run gemma4:31b-cloud # Cloud-hosted 31B
```

**Supported Applications:**
- Claude Code: `ollama launch claude --model gemma4`
- Codex: `ollama launch codex --model gemma4`
- OpenCode: `ollama launch opencode --model gemma4`
- OpenClaw: `ollama launch openclaw --model gemma4`

## Best Practices

### Sampling Parameters
```
temperature=1.0
top_p=0.95
top_k=64
```

### Thinking Mode
- Enable: Include `<|think|>` token in system prompt
- Disable: Remove the token
- For multi-turn: Don't include thinking content in history

### Multimodal Prompts
- Place image/audio content **before** text for optimal performance

### Image Resolution
- Lower budgets (70-140): Classification, captioning, video
- Higher budgets (560-1120): OCR, document parsing, small text

## Key Takeaways

1. **Efficiency champion**: Gemma 4 delivers top-tier performance at smaller sizes — the 31B model competes with models 20x larger

2. **True open source**: Apache 2.0 license allows commercial use without restrictions

3. **Local-first capable**: Edge models run on phones, Raspberry Pi, and NVIDIA Jetson; workstation models run on consumer GPUs with quantization

4. **Agent-ready**: Native function calling and system prompts make it ideal for building autonomous agents

5. **Multimodal by default**: All models handle text+image; edge models add audio

6. **Massive context**: 128K-256K context windows enable processing entire documents/repos
