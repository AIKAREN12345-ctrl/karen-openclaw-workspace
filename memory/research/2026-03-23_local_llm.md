Research summary of what's new for running models locally.

## 3. Ollama Updates
- **OpenAI Codex CLI support** (Jan 2026): Use local models like gpt-oss:20b/120b with Codex
- **Windows native**: Full GPU acceleration, OpenAI-compatible API
- **Python/JS libraries**: Mature integration options available

## 4. Key Trends
- **14B models** are the new sweet spot for 16GB RAM systems
- **Qwen 2.5 Coder** dominates coding tasks (85% HumanEval vs 68% Llama 3.3)
- **DeepSeek R1** brings visible chain-of-thought reasoning locally
- **Quantization**: Q4_K_M (default) balanced, Q8_0 for quality if RAM allows

## 5. Hardware Guidelines
- **8GB RAM**: Llama 3.3 8B or Mistral 7B
- **16GB RAM**: Qwen 2.5 14B, Phi-4, or DeepSeek R1 14B
- **32GB+ RAM**: DeepSeek R1 32B (near GPT-5.2 level reasoning)
