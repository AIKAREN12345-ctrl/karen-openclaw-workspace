## Latest Release: v2026.3.13 (March 14, 2026)

### New Features & Changes

#### Mobile & UI
- **Android/chat settings**: Complete redesign with grouped device and media sections, refreshed Connect and Voice tabs, tighter chat composer layout
- **iOS/onboarding**: First-run welcome pager before gateway setup, QR scanner no longer auto-opens, shows `/pair qr` instructions

#### Browser Automation (Major Updates)
- **Chrome DevTools MCP attach mode**: Official support for signed-in live Chrome sessions with documentation
- **New browser profiles**: Built-in `profile="user"` for logged-in host browser and `profile="chrome-relay"` for extension relay
- **Browser/act automation**: Batched actions, selector targeting, and delayed clicks with normalized batch dispatch

#### Docker & Infrastructure
- **Docker timezone override**: New `OPENCLAW_TZ` environment variable to pin gateway and CLI containers to chosen IANA timezone

#### Dependencies
- **Pi dependencies**: Bumped @mariozechner/pi-agent-core, pi-ai, pi-coding-agent, and pi-tui to 0.58.0

### Bug Fixes

#### Dashboard & UI
- **Dashboard v2 performance**: Stopped reloading full chat history on every live tool result - fixes UI freeze/re-render storms during tool-heavy runs
- **Chat UI**: Oversized plain-text replies now render as normal paragraphs instead of capped gray code blocks
- **New messages pill**: Restored proper compact styling for the scroll-to-new-messages button

#### Gateway & Connectivity
- **Gateway RPC timeout**: Rejected unanswered gateway RPC calls after bounded timeout - prevents hanging GatewayClient.request() promises
- **Session reset**: Preserves lastAccountId and lastThreadId across gateway session resets
- **macOS onboarding**: Fixed false-failures on slower Macs and fresh VM snapshots

#### Browser
- **Session lifecycle**: Hardened driver validation and session lifecycle with automatic reconnects on transport errors
- **Text-only responses**: Accepts text-only list_pages and new_page responses from Chrome DevTools MCP

#### Platform-Specific
- **Windows gateway**: Fixed install hanging on broken Scheduled Task setups, proper stop/kill for fallback processes
- **macOS exec approvals**: Respects per-agent exec approval settings in gateway prompter
- **Telegram**: Fixed media downloads with proper proxy transport policy, IPv4 fallback for file downloads
- **Discord**: Fixed gateway startup crashes on unhandled rejections

### Security Fixes

#### Critical
- **Device pairing**: Bootstrap setup codes are now single-use - prevents replay attacks
- **External content**: Strips zero-width and soft-hyphen marker-splitting characters to prevent spoofing
- **Exec approvals**: Multiple hardening improvements:
  - PowerShell `-File` and `-f` wrapper recognition
  - macOS shell-chain parsing with proper env dispatch unwrapping
  - Backslash-newline treated as shell line continuation
  - macOS skill auto-allow trust bound to both name and resolved path
  - Perl `-M`, `-I` flows fail closed
  - pnpm runtime forms unwrapping

#### Other Security
- **Telegram webhook**: Validates webhook secret before reading request bodies
- **iMessage attachments**: Rejects unsafe remote attachment paths before SCP
- **Control UI auth**: Preserves explicit shared token and password auth on plain-HTTP
