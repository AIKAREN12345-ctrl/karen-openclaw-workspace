## Recent Releases (March 2026)

### v2026.3.13 (Latest Stable) - March 14, 2025
**Status:** Immutable release

**New Features:**
- **Android/chat settings:** Redesigned chat settings sheet with grouped device and media sections, refreshed Connect and Voice tabs, tighter mobile layout
- **iOS/onboarding:** First-run welcome pager before gateway setup, QR scanner improvements
- **Browser/existing-session:** Official Chrome DevTools MCP attach mode for signed-in live Chrome sessions
- **Browser/agents:** New profiles: `profile="user"` for logged-in host browser, `profile="chrome-relay"` for extension relay
- **Browser/act automation:** Batched actions, selector targeting, delayed clicks
- **Docker:** `OPENCLAW_TZ` environment variable for timezone override

**Key Fixes:**
- **Dashboard/chat UI:** Fixed UI freeze/re-render storms during tool-heavy runs
- **Ollama/reasoning:** Stopped leaking internal thoughts from local reasoning models
- **Gateway/session reset:** Preserves `lastAccountId` and `lastThreadId` across resets
- **Windows/gateway:** Fixed install issues with Scheduled Task setups, improved stop/status commands
- **Telegram:** Fixed media downloads with proxy/IPv4 fallback
- **Security:** Multiple exec approval hardening fixes
