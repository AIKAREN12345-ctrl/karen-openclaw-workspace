## Key New Features

### 1. Context Engine Plugin Interface (#22201)
- New plugin slot with full lifecycle hooks: bootstrap, ingest, assemble, compact, afterTurn, prepareSubagentSpawn, onSubagentEnded
- Slot-based registry with config-driven resolution
- Enables alternative context management strategies without modifying core compaction logic

### 2. ACP Persistent Channel Bindings (#34873)
- Durable Discord channel and Telegram topic binding storage
- Routing resolution and CLI/docs support
- ACP thread targets now survive restarts

### 3. Telegram Topic Agent Routing (#33647)
- Support per-topic agentId overrides in forum groups and DM topics
- Topics can route to dedicated agents with isolated sessions

### 4. Web UI Internationalization (#35038)
- Added Spanish (es) locale support in Control UI
- Locale detection, lazy loading, and language picker labels

### 5. /btw Command for Side Questions (#45444)
- Clean way to ask quick side questions without polluting main session trajectory
- Reduces workflow interruption

### 6. Plugin Management Commands (In Development)
- Owner-gated /plugins and /plugin commands
- Marketplace-aware installs and updates
- Moving toward first-party install path via ClawHub
