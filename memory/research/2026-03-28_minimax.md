## OPEN SOURCE MODELS - Detailed Breakdown

### MiniMax-Text-01 (January 2025)
**GitHub:** https://github.com/MiniMax-AI/MiniMax-01 (3.4k stars, 318 forks)
**HuggingFace:** https://huggingface.co/MiniMaxAI/MiniMax-Text-01

**Architecture:**
- **Total Parameters:** 456 billion
- **Activated per Token:** 45.9 billion (Mixture-of-Experts)
- **Layers:** 80
- **Attention:** Hybrid - Lightning Attention + Softmax Attention (1 softmax per 7 lightning)
- **Context Window:** 1 million tokens training, 4 million tokens inference
- **Hidden Size:** 6144
- **Vocab Size:** 200,064
- **Experts:** 32 (top-2 routing)

**Key Innovation - Lightning Attention:**
Uses Linear Attention Sequence Parallelism Plus (LASP+) and varlen ring attention for efficient long-context processing.

## Deployment Options

### 1. vLLM (Recommended for Production)
Best throughput, memory management, batch processing

### 2. Transformers (Direct)
```python
from transformers import AutoModelForCausalLM, AutoTokenizer
model = AutoModelForCausalLM.from_pretrained(
    "MiniMaxAI/MiniMax-Text-01",
    torch_dtype="bfloat16",
    device_map="auto",
    trust_remote_code=True
)
```

### 3. Quantization
- int8 recommended for memory efficiency
- Requires custom config to exclude certain layers

### 4. Hardware Requirements
- Full model: ~8 GPUs
- Quantized: Fewer GPUs possible
- Supports device mapping across GPUs
