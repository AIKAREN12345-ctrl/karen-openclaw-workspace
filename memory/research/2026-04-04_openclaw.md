### Breaking Changes in 2026.4.2

1. **Plugins/xAI:** `x_search` settings moved from `tools.web.x_search.*` to `plugins.entries.xai.config.xSearch.*`. Auth now uses `XAI_API_KEY`. Migrate with `openclaw doctor --fix`.

2. **Plugins/web fetch:** Firecrawl `web_fetch` config moved from `tools.web.fetch.firecrawl.*` to `plugins.entries.firecrawl.config.webFetch.*`. Migrate with `openclaw doctor --fix`.

### Breaking Changes in 2026.3.2

1. **New install tool profile default:** Fresh installs default to `tools.profile: messaging` (no broad coding/system tools out of the box). Existing installs unaffected.

2. **ACP dispatch enabled by default:** `acp.dispatch.enabled` now defaults to `true`. Set explicitly to `false` to disable.

3. **Plugin HTTP handler API changed:** `api.registerHttpHandler(...)` removed. Use `api.registerHttpRoute({ path, auth, match, handler })` instead.
