## Major Updates and Changes

### 1. ContextEngine Plugin Architecture (v2026.3.7)

The most significant architectural change in 2026 is the introduction of the **ContextEngine** - a pluggable interface for context management that allows developers to implement custom context strategies without modifying core framework code.

**Lifecycle Hooks Available:**
- `bootstrap` - Initialize context
- `ingest` - Inject new information
- `assemble` - Construct final prompt context
- `compact` - Compress or trim context
- `afterTurn` - Post-processing after conversation turn
- `prepareSubagentSpawn` / `onSubagentEnded` - Sub-agent management

This enables custom RAG pipelines, aggressive summarization techniques, and isolated memory spaces for different sub-tasks.

### 2. Backup and Recovery Tools (v2026.3.8)

New CLI commands for data protection:
- `openclaw backup create` - Create local state archives
- `openclaw backup verify` - Validate backup integrity
- Options: `--only-config`, `--no-include-workspace`
- Includes manifest/payload validation

### 3. Enhanced Web Search Capabilities

- **Brave LLM Context mode**: Optional `tools.web.search.brave.mode: "llm-context"` returns extracted grounding snippets with source metadata
- **Perplexity Search API**: Switched to structured results with language/region/time filters
- **Provider ordering**: Alphabetized and neutral, with Grok now preferred before Kimi in auto-detect

### 4. Platform Integration Improvements

**Telegram:**
- Topic-level agent isolation (different agents per topic in same group)
- Persistent channel bindings for ACP workflows
- DM deduplication per agent instead of per session
- Actionable approval buttons with prefixed approval-id resolution

**Discord:**
- Connection freeze bug resolved
- Channel parsing optimizations
- `allowBots: "mentions"` option for bot mention gating

**macOS:**
- Remote gateway token field in onboarding
- Safer token preservation (non-plaintext values kept until explicitly replaced)
- Talk mode silence timeout configuration (`talk.silenceTimeoutMs`)
- Light/dark theme auto-detection via COLORFGBG

### 5. Security Hardening (v2026.2.12)

Major security-focused release addressing 40+ vulnerabilities:

**Critical Fixes:**
- **SSRF Protection**: Strict URL allowlists for `input_file` and `input_image` requests
- **Browser Control Authentication**: Now mandatory; auto-generates secure gateway token if none set
- **Prompt Injection Defense**: Browser/tool outputs sanitized before model processing
- **Hooks Security**: Constant-time secret comparisons, per-client rate limiting
- **Session Key Override Protection**: POST /hooks/agent blocks payload sessionKey overrides by default

**Additional Security Measures:**
- Audit logging for blocked fetch attempts
- Nostr profile configuration tampering fix
- Transcript path validation tightened
- Signed Mac packages with SHA-256 verification

## Security Advisories

### CVE-2026-25253
- **Issue**: WebSocket hijacking vulnerability
- **Status**: Patched in recent releases
- **Action**: Users strongly encouraged to update to latest version

### Previous RCE Concerns Addressed
- Loopback browser control previously linked to one-click RCE and token leaks
- Now requires mandatory authentication
- Audit checks flag unauthenticated browser control routes

### Best Practices Recommended
1. Update to 2026.2.12 or later immediately
2. Configure explicit `gateway.auth.mode` when using both token and password
3. Review and tighten hook configurations
4. Enable audit logging for security monitoring
