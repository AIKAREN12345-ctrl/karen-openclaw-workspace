# AI Model Releases Research - 2026-03-15

## OpenAI GPT-5.4 (March 5, 2026)

OpenAI released GPT-5.4, their most capable and efficient frontier model for professional work. Key highlights:

### Key Features:
- **1M token context window** - Largest context window from OpenAI
- **Native computer-use capabilities** - First general-purpose model with state-of-the-art computer use
- **Tool Search** - New system for efficient tool calling that reduces token usage by up to 47%
- **33% fewer hallucinations** compared to GPT-5.2
- **18% fewer errors** in overall responses

### Versions Available:
- GPT-5.4 (standard)
- GPT-5.4 Thinking (reasoning model with upfront planning)
- GPT-5.4 Pro (maximum performance for complex tasks)

### Benchmark Performance:
- **GDPval**: 83.0% (vs 70.9% for GPT-5.2)
- **SWE-Bench Pro**: 57.7%
- **OSWorld-Verified**: 75.0% (exceeds human performance at 72.4%)
- **BrowseComp**: 82.7% (17% improvement over GPT-5.2)
- **Toolathlon**: 54.6%

### Pricing (API):
- GPT-5.4: $2.50/M input tokens, $15/M output tokens
- GPT-5.4 Pro: $30/M input tokens, $180/M output tokens
