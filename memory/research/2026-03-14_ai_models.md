### NVIDIA NeMo Retriever - Agentic Retrieval Pipeline (Released March 13, 2026)

**Achievement:**
- **#1 on ViDoRe v3 pipeline leaderboard** (69.22 NDCG@10)
- **#2 on BRIGHT leaderboard** (50.90 NDCG@10) - reasoning-intensive benchmark

**Key Innovation:**
- Agentic retrieval pipeline using ReACT architecture
- Iterative search, evaluation, and refinement loop
- Dynamically adjusts search queries based on discovered information
- Breaks complex queries into multiple simpler queries

**Technical Approach:**
- Replaces MCP server with thread-safe singleton retriever (in-process)
- Eliminates network serialization overhead
- Uses Opus 4.5 + nemotron-colembed-vl-8b-v2 for best results
- Falls back to Reciprocal Rank Fusion (RRF) when hitting limits

**Tradeoffs:**
- Averages 136 seconds per query (vs 0.67s for dense retrieval)
- ~760k input tokens and 6.3k output tokens per query
- Best for high-stakes, complex queries

### Hugging Face Modular Diffusers (Released March 5, 2026)

**New composable building blocks for diffusion pipelines**

**Key Features:**
- Mix and match blocks instead of writing pipelines from scratch
- Each block is self-contained with own inputs/outputs
- Blocks dynamically recompose to work with whatever remains
- Lazy loading and memory management with ComponentsManager

**Community Pipelines:**
- **Krea Realtime Video** - 14B parameter real-time video generation, 11fps on B200 GPU
- **Waypoint-1** - 2.3B parameter real-time diffusion world model from Overworld

**Integration:**
- Works with Mellon (node-based visual workflow interface)
- Hub integration out of the box
- Custom blocks can be published to Hub

### Hugging Face Storage Buckets (Released March 10, 2026)

**New S3-like object storage for ML artifacts**

**Purpose:**
- Mutable storage for checkpoints, optimizer states, processed shards, logs, traces
- Built on Xet (chunk-based storage with deduplication)
- Pre-warming support to bring data close to compute (AWS/GCP)

**Features:**
- Non-versioned storage containers
- Standard Hugging Face permissions (private/public)
- CLI and Python API support
- fsspec-compatible filesystem integration
- Works with pandas, Polars, Dask
