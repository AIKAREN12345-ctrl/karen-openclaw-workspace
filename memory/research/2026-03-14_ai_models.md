## Open Source Model Releases

### Lightricks LTX 2.3
**Source:** Sci-Tech Today

- 22-billion-parameter Diffusion Transformer (DiT) model
- Generates synchronized video and audio in a single pass
- Native 4K at 50 FPS, portrait-mode 1080×1920
- Four checkpoint variants: dev, distilled, fast, and pro
- Distilled variant: 8 denoising steps for rapid iteration
- Rebuilt VAE for sharper textures and edge detail

### Helios (Peking University, ByteDance, Canva)
**Source:** Sci-Tech Today

- 14B autoregressive diffusion model
- 19.5 FPS real-time video generation on single NVIDIA H100 GPU
- Generates videos up to 1,440 frames (~1 minute at 24 FPS)
- Apache 2.0 license (free for commercial use)
- Supports T2V, I2V, and V2V through unified input representation
- No KV-cache, no quantization, no sparse attention needed
- Deep Compression Flow and Easy Anti-Drifting strategies

### Alibaba Qwen 3.5 Small Series (Released March 1, 2026)
**Source:** Sci-Tech Today

Four dense model variants: 0.8B, 2B, 4B, and 9B parameters
- 9B model matches GPT-OSS-120B (13× its size) on benchmarks
- GPQA Diamond: 81.7 vs 71.5
- HMMT Feb 2025: 83.2 vs 76.7
- 2B model runs on any recent iPhone in airplane mode (4GB RAM)
- Designed for on-device AI deployment

### CUDA Agent (ByteDance Seed + Tsinghua University)
**Source:** Sci-Tech Today

- Agentic reinforcement learning system for automatic CUDA kernel generation
- Three-level curriculum: element-wise → multi-stage kernels (attention)
- KernelBench: 100% faster on Level-1/2, 92% on Level-3
- Outperforms Claude Opus 4 and Gemini 3 Pro by 40% on hardest tasks

### Kiwi-Edit (NUS ShowLab)
**Source:** Sci-Tech Today

- Video editing combining text instructions with reference images
- Built on Qwen2.5-VL-3B and Wan2.2-TI2V-5B
- Trained on 477,000 high-quality quadruplets
- OpenVE-Bench: 3.02 overall (highest among open-source methods)
- MIT-licensed with full code, models, and datasets public

### FireRed-Image-Edit-1.1
**Source:** Sci-Tech Today

- Universal image editing model
- State-of-the-art identity consistency
- Multi-element fusion with 10+ elements via agent-powered pipeline
- Comprehensive portrait makeup across hundreds of styles
- Supports ComfyUI nodes and GGUF lightweight formats
