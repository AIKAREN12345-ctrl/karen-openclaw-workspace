## Major Release: OpenClaw 2026.3.22 (March 22, 2026)

This is a **major release** with significant changes - described as "The Biggest Release Yet" with:
- **23 Breaking Changes**
- **80+ New Features**
- **100+ Bug Fixes**
- **30+ Security Hardening Patches**

### Key Breaking Changes

1. **Plugin Installation:** Bare `openclaw plugins install` now prefers **ClawHub** before npm for npm-safe names, only falling back to npm when ClawHub doesn't have the package/version.

2. **Browser/Chrome MCP:** Removed legacy Chrome extension relay path, bundled extension assets, `driver: "extension"`, and `browser.relayBindHost`. Users need to run `openclaw doctor --fix` to migrate.

3. **Image Generation:** Standardized on core `image_generate` tool. Removed bundled nano-banana-pro skill wrapper.

4. **Plugin SDK:** New public plugin SDK surface is `openclaw/plugin-sdk/*`; `openclaw/extension-api` is removed with no compatibility shim.

5. **Matrix Plugin:** New Matrix plugin backed by official matrix-js-sdk (migration guide available).

6. **Legacy Config Removal:** Removed `CLAWDBOT_*` and `MOLTBOT_*` env compatibility names, and `.moltbot` state-dir auto-detection.

### Major New Features

1. **ClawHub Marketplace:** Native `openclaw skills search|install|update` flows plus `openclaw plugins install clawhub:` with tracked update metadata.

2. **Plugin Marketplace Support:** Added Claude marketplace registry resolution, plugin@marketplace installs, and marketplace listing support.

3. **New Model Support:**
   - Default OpenAI model switched to **openai/gpt-5.4**
   - Codex stays on openai-codex/gpt-5.4
   - Forward-compat support for gpt-5.4-mini and gpt-5.4-nano
   - Added **Anthropic Vertex** provider support for Claude via Google Vertex AI
   - Added **Chutes** provider with OAuth/API-key auth

4. **New Web Search Tools:**
   - **Exa** as bundled web-search plugin
   - **Tavily** as bundled web-search provider
   - **Firecrawl** as onboard/configure search provider

5. **Sandbox Improvements:**
   - Pluggable sandbox backends
   - OpenShell backend with mirror and remote workspace modes
   - Core SSH sandbox backend with secret-backed key support

6. **Browser Enhancements:** Support for `browser.profiles..userDataDir` so Chrome DevTools MCP can attach to Brave, Edge, and other Chromium browsers.

7. **New Commands:**
   - `/btw` side questions for quick tool-less answers
   - `/plugins` and `/plugin` chat commands for plugin management

## Latest Patch Release: 2026.3.23 (March 23, 2026)

Released March 23 at 23:15 - includes fixes for issues introduced in 2026.3.22.

### Changes
- ModelStudio/Qwen: Added standard DashScope endpoints for China and global Qwen API keys
- UI/clarity: Consolidated button primitives, refined Knot theme (black-and-red palette), improved accessibility
- CSP/Control UI: Compute SHA-256 hashes for inline blocks in served index.html

### Key Fixes
- **Plugins:** Bundled plugin runtime sidecars shipped in npm package again (fixes global install failures)
- **CLI/Channel Auth:** Auto-select single configured login-capable channel; harden channel ids against abuse
- **Auth/OpenAI:** Fixed live gateway auth-profile writes reverting saved credentials
- **Control UI/Auth:** Preserve operator scopes through device-auth bypass path
- **Plugins/ClawHub:** Resolve plugin API compatibility against active runtime version
- **Browser/Chrome MCP:** Wait for existing-session browser tabs to become usable after attach (reduces timeouts)
- **Browser/CDP:** Reuse already-running loopback browser after short reachability miss
- **Agents/web_search:** Use active runtime web_search provider instead of stale/default selection
- **Mistral:** Lowered bundled max-token defaults to avoid 422 rejects
- **ClawHub/macOS:** Honor macOS auth config and XDG auth paths
- **Cron:** Honor requested local wall-clock time for offset-less one-shot datetimes
- **LINE Runtime:** Fixed TypeError on startup
- **Telegram:** Threading and media transport fixes
- **Discord:** Return explicit unauthorized reply for privileged native slash commands

## Security Highlights

- **Exec/Env Sandbox:** Blocked build-tool JVM injection, glibc tunable exploitation, .NET dependency resolution hijack
- **Voice-call/Webhooks:** Reject missing provider signatures, drop pre-auth body budget to 64KB/5s, cap concurrent pre-auth requests
- **Security/Exec Approvals:** Treat `time` as transparent dispatch wrapper
- **CSP:** Added SHA-256 hash computation for inline scripts

## Summary

The OpenClaw project is moving rapidly with the 2026.3.22 major release being a significant milestone. The shift toward **ClawHub** as the primary plugin marketplace, the **plugin SDK refactoring**, and the **new model integrations** (GPT-5.4, Anthropic Vertex, Chutes) are the biggest changes. Users should run `openclaw doctor --fix` after upgrading to handle configuration migrations.

The 2026.3.23 patch released just yesterday addresses several issues from the major release, particularly around plugin installation and browser MCP stability.
