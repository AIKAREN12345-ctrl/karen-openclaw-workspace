## Summary

The first week of March 2026 unleashed one of the most concentrated bursts of AI releases in recent memory. Over just seven days (March 1–8), organizations including OpenAI, Alibaba, Lightricks, Tencent, Meta, ByteDance, and several leading universities announced at least 12 major AI models and tools.

## Major Model Releases

### 1. OpenAI GPT-5.4 (March 5, 2026)
- **Context Window:** 1.05 million tokens (largest OpenAI has ever offered)
- **Variants:** Standard, Thinking (reasoning-first), Pro (maximum capability)
- **Improvements:** 33% fewer factual errors, 18% fewer full-response errors vs GPT-5.2
- **Pricing:** $2.50 per 1M input tokens, $15.00 per 1M output tokens
- **Key Feature:** Tool Search - dynamically looks up tool definitions rather than loading all into prompt
- **Benchmark:** Record 83% on OpenAI's GDPval benchmark for knowledge work

### 2. Lightricks LTX 2.3
- **Parameters:** 22 billion
- **Type:** Open-source Diffusion Transformer (DiT) video model
- **Capabilities:** Native 4K at 50 FPS, synchronized audio-video generation
- **Duration:** Up to 20 seconds
- **Variants:** dev, distilled, fast, and pro checkpoints
- **Features:** Portrait-mode support (1080×1920), rebuilt VAE for sharper textures

### 3. Helios (PKU/ByteDance/Canva)
- **Parameters:** 14 billion
- **Type:** Autoregressive diffusion model
- **Speed:** 19.5 FPS real-time video generation on single NVIDIA H100
- **Duration:** Up to 1 minute (1,440 frames at 24 FPS)
- **License:** Apache 2.0 (free for commercial use)
- **Features:** No KV-cache, no quantization needed; supports T2V, I2V, V2V

### 4. Alibaba Qwen 3.5 Small Series (March 1, 2026)
- **Variants:** 0.8B, 2B, 4B, 9B parameters
- **Performance:** 9B model matches GPT-OSS-120B (13× its size)
- **On-device:** 2B model runs on iPhone in airplane mode with 4GB RAM
- **Benchmarks:** GPQA Diamond (81.7 vs 71.5), HMMT Feb 2025 (83.2 vs 76.7)

### 5. CUDA Agent (ByteDance/Tsinghua)
- **Purpose:** Automatic CUDA kernel generation via agentic reinforcement learning
- **Performance:** 100% faster on KernelBench Level-1/2, 92% on Level-3
- **Advantage:** Outperforms Claude Opus 4 and Gemini 3 Pro by 40% on hardest tasks

### 6. Other Notable Releases
- **FireRed Edit 1.1:** Universal image editing model with agent-powered pipeline
- **Kiwi Edit (NUS):** Video editing framework scoring 3.02 on OpenVE-Bench
- **CubeComposer:** Native 4K 360° video generation using cubemaps
- **SpatialT2I:** Dataset for improving spatial intelligence in T2I models
- **Spectrum:** Training-free spectral diffusion achieving 4.79× speedup on FLUX.1
- **Utonia (Meta):** Universal self-supervised point transformer encoder
- **HY-WorldPlay (Tencent):** RL post-training for real-time interactive world models

## Key Trends
