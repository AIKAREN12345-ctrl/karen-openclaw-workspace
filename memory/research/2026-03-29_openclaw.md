## OpenClaw Research - 2026-03-29 06:00

### Latest Stable Release: v2026.3.28 (March 28, 2026)

**Major Updates & Features:**
- **Plugin Approval System**: New async `requireApproval` hook lets plugins pause tool execution and route approval through overlays, Telegram buttons, Discord interactions, or `/approve` command
- **ACP Chat Binding**: Current-conversation binds for Discord, BlueBubbles, and iMessage - turn live conversations into Codex-backed workspaces with `/acp spawn ... --bind here`
- **xAI/Grok Integration**: Bundled xAI provider moved to Responses API with first-class x_search support; auto-enables from web-search config
- **MiniMax Image Generation**: New provider for image-01 model supporting generate and image-to-image editing with aspect ratio control
- **OpenAI apply_patch**: Enabled by default for OpenAI and OpenAI Codex models with aligned sandbox policy access
- **CLI Backend Plugins**: Bundled Claude CLI, Codex CLI, and Gemini CLI inference defaults moved to plugin surface with auto-loading

**Breaking Changes:**
- **Qwen Provider**: Removed deprecated qwen-portal-auth OAuth integration; migrate to Model Studio with `openclaw onboard --auth-choice modelstudio-api-key`
- **Config/Doctor**: Dropped automatic config migrations older than two months; legacy keys now fail validation instead of being rewritten

**Notable Fixes:**
- Anthropic: Recover unhandled provider stop reasons (e.g., "sensitive") as structured errors instead of crashing
- Google models: Resolve Gemini 3.1 pro, flash, and flash-lite for all provider aliases
- WhatsApp: Fixed infinite echo loop in self-chat DM mode
- Telegram: Long messages now split at word boundaries instead of mid-word
- Discord: Gateway reconnect improvements to stop looping on poisoned resume state

### Previous Release: v2026.3.24 (March 24, 2026)

**Key Features:**
- **OpenAI-Compatible API**: Gateway now exposes `/v1/models` and `/v1/embeddings`, forwards model overrides through `/v1/chat/completions` and `/v1/responses`
- **Microsoft Teams SDK**: Full migration to official Teams SDK with streaming replies, welcome cards, typing indicators, AI labeling, message edit/delete
- **Skills UI Overhaul**: Status-filter tabs (All/Ready/Needs Setup/Disabled), one-click install recipes for bundled skills
- **Container CLI**: `openclaw --container` runs commands inside Docker/Podman containers from host
- **Discord Auto-Threads**: Optional `autoThreadName: "generated"` for LLM-generated thread titles
- **Slack Interactive Replies**: Options: lines auto-render as buttons/selects
