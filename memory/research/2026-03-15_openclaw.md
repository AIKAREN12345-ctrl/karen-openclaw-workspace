## Latest Release: v2026.3.13-1 (Recovery Release)
**Date:** March 14, 2026

**Note:** This is a recovery release using v2026.3.13-1 tag because GitHub immutable releases do not allow reusing v2026.3.13 after publication. The npm version is still 2026.3.13.

### Key Fixes in v2026.3.13-1:
- **fix(compaction):** use full-session token count for post-compaction sanity check
- **fix(telegram):** thread media transport policy into SSRF
- **fix:** handle Discord gateway metadata fetch failures
- **fix(session):** preserve lastAccountId and lastThreadId on session reset
- **fix(agents):** drop Anthropic thinking blocks on replay
- **fix(agents):** avoid injecting memory file twice on case-insensitive mounts
- **Docker:** add OPENCLAW_TZ timezone support
- **Android:** fix HttpURLConnection leak in TalkModeVoiceResolver
- **fix(agents):** respect explicit user compat overrides for non-native openai-completions
- **fix(agents):** rephrase session reset prompt to avoid Azure content filter
- **fix(config):** add missing params field to agents.list[] validation schema
- **fix(android):** use Google Code Scanner for onboarding QR
- **fix(windows):** suppress visible console windows during restart and process cleanup
- **fix(cron):** prevent isolated cron nested lane deadlocks
- **fix(browser):** normalize batch act dispatch for selector and batch support
- **security(docker):** prevent gateway token leak in Docker build context
- **fix(ollama):** hide native reasoning-only output
- **fix(gateway):** bound unanswered client requests
- **fix(sessions):** create transcript file on chat.inject when missing
- **fix(macos):** prevent PortGuard from killing Docker Desktop in remote mode
- **fix(feishu):** add early event-level dedup to prevent duplicate replies
- **fix(browser):** harden existing-session driver validation and session lifecycle

## v2026.3.13-beta.1 (Pre-release)
**Date:** March 14, 2026

### New Features:
- **Android/chat settings:** redesign with grouped device and media sections
- **iOS/onboarding:** add first-run welcome pager before gateway setup
- **Browser/existing-session:** add official Chrome DevTools MCP attach mode for signed-in live Chrome sessions
- **Browser/agents:** add built-in profile="user" for logged-in host browser and profile="chrome-relay" for extension relay
- **Browser/act automation:** add batched actions, selector targeting, and delayed clicks
- **Docker/timezone:** add OPENCLAW_TZ for pinning gateway and CLI containers to chosen IANA timezone

### Notable Fixes:
- **Dashboard/chat UI:** stop reloading full chat history on every live tool result (fixes UI freeze/re-render storms)
- **Ollama/reasoning:** stop promoting native thinking/reasoning fields into final assistant text
- **Android/onboarding:** switch setup QR scanning to Google Code Scanner
- **Browser/existing-session:** harden driver validation and session lifecycle
- **Control UI/insecure auth:** preserve explicit shared token and password auth on plain-HTTP connects
- **Gateway/session reset:** preserve lastAccountId and lastThreadId across resets
- **macOS/onboarding:** avoid self-restarting freshly bootstrapped launchd gateways
- **macOS/exec approvals:** respect per-agent exec approval settings in gateway prompter
- **Telegram/media:** thread transport policy into SSRF-guarded file fetches
- **Windows/gateway:** multiple fixes for install, stop, status, and auth handling
- **Discord/gateway:** treat metadata fetch failures as transient startup errors
- **Security/device pairing:** make bootstrap setup codes single-use
- **Security/external content:** strip zero-width characters during boundary sanitization
- **Build/plugin-sdk:** deduplicate plugin-sdk chunks to fix ~2x memory regression

## v2026.3.12 (Stable Release)
**Date:** March 12, 2026

### Security:
- **Gateway/WebSocket:** enforce browser origin validation for all browser-originated connections (closes cross-site WebSocket hijacking path)

### New Features:
- **Control UI/dashboard-v2:** refresh with modular overview, chat, config, agent, and session views
- **OpenAI/GPT-5.4 fast mode:** configurable session-level fast toggles
- **Anthropic/Claude fast mode:** map shared /fast toggle to direct Anthropic API service_tier requests
- **Models/plugins:** move Ollama, vLLM, and SGLang onto provider-plugin architecture
- **Docs/Kubernetes:** add starter K8s install path
- **Agents/subagents:** add sessions_yield for orchestrators to end current turn immediately
- **Slack/agent replies:** support channelData.slack.blocks for Block Kit messages
- **OpenRouter/models:** add Hunter Alpha and Healer Alpha entries
- **iOS/Home canvas:** bundled welcome screen with live agent overview
- **macOS/chat UI:** chat model picker with persistent thinking-level selections
- **Onboarding/Ollama:** first-class Ollama setup with Local or Cloud + Local modes
- **OpenCode/onboarding:** add new OpenCode Go provider
- **Memory:** opt-in multimodal image and audio indexing with Gemini embedding support
- **Discord/auto threads:** add autoArchiveDuration channel config
- **ACP/sessions_spawn:** add optional resumeSessionId for resuming existing ACP conversations

### Breaking Changes:
- **Cron/doctor:** tighten isolated cron delivery (cron jobs can no longer notify through ad hoc agent sends)

### Notable Fixes:
- **Security/device pairing:** switch to short-lived bootstrap tokens
- **Security/plugins:** disable implicit workspace plugin auto-load (GHSA-99qw-6mr3-36qr)
- **Models/Kimi Coding:** send anthropic-messages tools in native Anthropic format
- **TUI/chat log:** fix duplicate assistant replies in streaming
- **Telegram/model picker:** fix inline model button selections
- **Cron/proactive delivery:** keep isolated direct cron sends out of write-ahead resend queue
- **BlueBubbles/self-chat:** fix echo dedupe
- **iMessage/self-chat:** fix echo dedupe
- **Subagents/completion:** raise default announce timeout to 90 seconds
- **Mattermost:** fix duplicate message delivery and reply media delivery
- **macOS/Reminders:** add NSRemindersUsageDescription
- **Security:** multiple exec approval, auth, and sandbox hardening fixes
