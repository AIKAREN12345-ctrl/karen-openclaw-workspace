## Latest Stable Release: v2026.3.13 (Recovery: v2026.3.13-1)

**Release Date:** March 13-14, 2026

### Key Updates in v2026.3.13

#### New Features
- **Browser Control Enhancements:**
  - Official Chrome DevTools MCP attach mode for signed-in browser sessions
  - Built-in browser profiles: `profile="user"` for logged-in host browser, `profile="chrome-relay"` for extension relay
  - Browser act automation with batched actions, selector targeting, and delayed clicks
  - Hardened driver validation and session lifecycle

- **Mobile Improvements:**
  - Android: Redesigned chat settings UI with grouped device and media sections
  - iOS: New onboarding welcome pager before gateway setup
  - Android: Google Code Scanner for onboarding QR (more reliable than legacy ZXing)

- **Docker & Infrastructure:**
  - Docker timezone override support via `OPENCLAW_TZ` environment variable
  - Added `apt-get upgrade` to all Dockerfiles

- **Model Support:**
  - Updated default model from `openai-codex/gpt-5.3-codex` to `openai-codex/gpt-5.4`
  - Ollama: Hide native reasoning-only output to prevent leaking internal thoughts

#### Bug Fixes
- **Dashboard/UI:**
  - Fixed chat history reload storm in dashboard v2
  - Restored chat-new-messages class on scroll pill button
  - Fixed oversized chat replies rendering
  - Fixed chat context notice icon sizing

- **Security:**
  - Security: Prevent gateway token leak in Docker build context
  - Security: Single-use bootstrap setup codes for device pairing
  - Security: Strip zero-width characters during boundary sanitization
  - Security: Various exec approval hardening improvements

- **Platform-Specific:**
  - Windows: Suppress visible console windows during restart and process cleanup
  - macOS: Respect exec-approvals.json settings in gateway prompter
  - macOS: Prevent PortGuard from killing Docker Desktop in remote mode
  - macOS: Align minimum Node.js version with runtime guard (22.16.0)

- **Channels:**
  - Telegram: Retry inbound media downloads over IPv4 fallback
  - Telegram: Thread media transport policy into SSRF
  - Discord: Handle gateway metadata fetch failures gracefully
  - Feishu: Preserve non-ASCII filenames in file uploads
  - Signal: Add groups config to Signal channel schema

#### Breaking Changes
- None major in this release (recovery release focused on fixes)

## Previous Release: v2026.3.12

**Release Date:** March 12, 2026

### Major Changes
- **Security:** Enforced browser origin validation for all browser-originated connections (closes cross-site WebSocket hijacking path)
- **Fast Mode:** Shared `/fast` mode toggle across OpenAI and Anthropic paths
- **Ollama:** First-class Ollama onboarding with Local or Cloud + Local modes
- **Dashboard:** Refreshed Control UI/dashboard-v2 with modular views
- **Memory:** Opt-in multimodal image and audio indexing with Gemini embedding support
- **ACP Sessions:** Resumable ACP sessions via `resumeSessionId`

### Security Highlights
- Short-lived bootstrap pairing tokens (security hardening)
- Disabled implicit workspace plugin auto-load (prevents cloned repos from executing code without explicit trust)
- Multiple security advisories addressed (GHSA-99qw-6mr3-36qr, GHSA-pcqg-f7rg-xfvv, GHSA-9r3v-37xh-2cf6, etc.)

## Community News & Trends

### Development Direction
1. **Security-First Approach:** Active focus on closing media trust bypasses, treating empty URL allowlists as deny-all rules, and tightening approval/channel boundaries

2. **Modular Architecture:** 
   - Pluggable sandbox backends
   - Bundled provider plugins
   - Firecrawl-backed web tooling
   - Moving toward modular control plane instead of monolithic design

3. **Browser Automation Evolution:**
   - Moving from Chrome extension relay to existing-session/user browser attachment
   - Support for Chromium-family profiles via userDataDir
   - More reliable automation for signed-in sessions

4. **Operator Experience:**
   - Plugin management becoming first-class chat workflow
   - Config changes getting safer with `--dry-run` validation
   - Better backup/verify capabilities
