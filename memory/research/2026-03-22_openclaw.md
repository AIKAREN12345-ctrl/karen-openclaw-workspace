## Latest Release: v2026.3.13-1 (March 14, 2026)

This is a recovery release that uses v2026.3.13-1 because GitHub immutable releases do not allow reusing v2026.3.13 after publication.

### Key Bug Fixes

#### Critical Fixes
- **Compaction:** Use full-session token count for post-compaction sanity check
- **Telegram:** Thread media transport policy into SSRF for secure file downloads
- **Discord:** Handle gateway metadata fetch failures gracefully
- **Session:** Preserve lastAccountId and lastThreadId on session reset
- **Agents:** Drop Anthropic thinking blocks on replay
- **Agents:** Avoid injecting memory file twice on case-insensitive mounts

#### Platform-Specific Fixes
- **Windows:** Suppress visible console windows during restart and process cleanup
- **macOS:** Prevent PortGuard from killing Docker Desktop in remote mode
- **macOS:** Align minimum Node.js version with runtime guard (22.16.0)
- **Android:** Fix HttpURLConnection leak in TalkModeVoiceResolver
- **Android:** Use Google Code Scanner for onboarding QR
- **iOS:** Add onboarding welcome pager

#### Browser & Gateway Fixes
- **Browser:** Normalize batch act dispatch for selector and batch support
- **Browser:** Harden existing-session driver validation and session lifecycle
- **Gateway:** Bound unanswered client requests
- **Gateway:** Restore control-ui auth bypass and classify connect failures
- **UI:** Stop dashboard chat history reload storm
- **UI:** Keep oversized chat replies readable

#### Model & Provider Fixes
- **Ollama:** Hide native reasoning-only output
- **Models:** Apply Gemini model-id normalization to google-vertex provider
- **Agents:** Respect explicit user compat overrides for non-native openai-completions
- **Agents:** Preserve blank local custom-provider API keys after onboarding

## Previous Release: v2026.3.13-beta.1 (March 14, 2026)

- **Android/Chat Settings:** Redesigned chat settings sheet with grouped device and media sections

- **Security/Device Pairing:** Make bootstrap setup codes single-use
- **Security/External Content:** Strip zero-width and soft-hyphen marker-splitting characters
- **Security/Exec Approvals:** Multiple hardening improvements for PowerShell, Perl, Ruby, and macOS
