## Security Research - 2026-04-09 17:15

- **AI Agent Threat Landscape (2026)** — A comprehensive security guide reports that 36.8% of AI agent skills contain security flaws (Snyk/ClawHub 2026), 76 malicious skills confirmed in registries, and 85.6% of agents lack full security review. Only 14.4% of organizations report all agents go live with security approval. The Promptware Kill Chain identifies 7 stages from initial access to actions on objective. Source: <https://www.oktsec.com/ai-agent-security/>

- **18-Item Security Checklist** — A practical 2026 checklist covers 5 threat vectors: prompt injection, credential exposure, supply chain attacks, data exfiltration, and unauthorized actions. Key controls: action allowlists (not blocklists), secondary validation LLM calls for high-risk actions, secrets managers (Doppler/Vault), Docker sandboxing, dependency pinning with hash verification, rate limits on every tool call, and full tool-call logging with anomaly alerts. Source: <https://paxrel.com/blog-ai-agent-security.html>

- **Cost of Insecurity** — Leaked API keys from crypto mining: $500–$10,000. Mass unsolicited emails: domain blacklisted for months. Customer data exfiltration: GDPR fines up to 4% of revenue. Total baseline security stack (Doppler + Docker + Langfuse + pip-audit + rate limits): $0/month and ~8 hours to implement. Source: <https://paxrel.com/blog-ai-agent-security.html>
