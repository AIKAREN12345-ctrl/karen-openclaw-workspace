## Windows Optimizations

### Key Recommendations for Windows Users

1. **Quantization Selection**
   - Use Q4_K_M or Q5_K_M for best speed/quality balance
   - Avoid Q8_0 unless precision critical
   - Q3 and below causes 5-8% degradation on multi-step reasoning

2. **VRAM Management**
   - Ensure entire model fits in VRAM (spilling to RAM = 90%+ performance drop)
   - 16GB card: stick to 12B-14B models at 4-bit
   - 24GB card: can run 32B models at Q4_K_M

3. **Context Window**
   - Limit to 8k-16k unless specifically needed
   - Large contexts consume massive KV cache

4. **Ollama Autotune (PR #15081)**
   - Automatic hardware-based performance optimization
   - Currently in PR stage, not yet merged

### Windows-Specific Tips
- Monitor GPU thermals with `nvidia-smi`
- Thermal throttling can reduce sustained speeds by up to 15%
- Ensure proper cooling for long inference sessions
